# Marque : Bibou, par Yasal Santé

Yasal Santé est la marque mère ; **Bibou** est le nom de la boutique. Les fichiers d'origine
sont dans `docs/marque/` (PNG transparents, grande taille) ; les déclinaisons pour le web sont
générées dans `web/boutique/public/` et `web/charte/public/marque/`.

## Logo principal de Bibou : le bleu, papillon et nom

`bibou-bleu.png`. Choisi parce que :

- c'est la version la plus lisible sur un téléphone, même en plein soleil : le bleu `#1000d0`
  offre un contraste de 10,9:1 sur fond blanc (le vert `#90b840` n'en offre que 2,3:1) ;
- il distingue la boutique de la marque mère, verte et rouge ;
- l'orange du sourire ressort sur le bleu comme sur le blanc.

| Usage | Fichier |
| --- | --- |
| Site, réseaux sociaux, documents en couleur | `bibou-bleu.png` |
| Une seule couleur : broderie, tampon, facture imprimée en noir | `bibou-noir.png` |
| Sur fond foncé ou sur une photo | `bibou-blanc.png` |
| Icône d'application, favicon, photo de profil WhatsApp | `bibou-papillon-bleu.png` |
| Usage saisonnier ou décoratif, jamais pour un petit texte | versions vertes |

## Couleurs

| Nom | Valeur | Emploi |
| --- | --- | --- |
| Bleu Bibou | `#1000d0` | couleur principale, boutons, liens |
| Bleu nuit | `#0b0096` | survol, appui |
| Orange sourire | `#f89800` | aplats et décor ; texte foncé dessus, jamais de texte orange sur blanc |
| Encre | `#17153a` | texte |
| Vert Yasal Santé | `#38b070` (`#177a4a` pour un fond de bouton) | marque mère |
| Rouge Yasal Santé | `#d02038` | marque mère |

## Règles

- Le logo garde ses proportions et un espace libre autour de lui au moins égal à la hauteur de
  la lettre « o ».
- Pas d'ombre, de contour ni de déformation ; pas de logo bleu sur fond vert ou rouge.
- La mention « par Yasal Santé » ou « une marque de Yasal Santé » accompagne Bibou dans l'en-tête
  et le pied de page du site, sur les devis et sur les factures.
- Les polices restent celles du système (aucun téléchargement de police : forfaits data coûteux).
